Install InkDeck

Markdown writing and a daily journal for the Xteink X3/X4, synced with GitJournal. Install it from this page, then set up Wi-Fi and your journal repository without touching a config file.

Your browser can't talk to USB devices. Use Chrome or Edge on a computer (not Safari, Firefox, or a phone). This page has to be opened over HTTPS (or from localhost) to reach USB devices.

Plug the X4 into this computer with a USB-C data cable and wake it, then press the button and pick the port named USB JTAG/serial debug unit.

What happens

  1. Install. The installer writes InkDeck to the X4 (about a minute). Choose erase for a clean install; it clears saved Wi-Fi and Bluetooth pairings, not your SD card.
  2. Wi-Fi. When the X4 restarts, the installer asks for your Wi-Fi network and password and sends them over the USB cable. Use a 2.4 GHz network.
  3. Your journal. Choose Visit Device. A setup page opens from the X4 itself (its address and a QR code are also on its screen). Paste the repository URL from GitJournal (Settings → Git Remote Settings → Git Host) and an access token, and check the time zone. Then press OK on the X4 to sync.
The X4 turns Bluetooth off while it's on Wi-Fi, so a paired keyboard reconnects once setup or sync finishes. To change settings later, use Menu → Setup over Wi-Fi on the device.

Access token

GitJournal signs in with an SSH key; the X4 uses an access token instead. On GitHub, create a fine-grained token for your journal repository only, with Contents: Read and write.

GitHub is the only provider InkDeck syncs with so far. The token and Wi-Fi password are stored on the X4 and sent only to GitHub and your network.

If it doesn't connect

  1. Check the cable carries data (some USB-C cables only charge).
  2. Close any other program using the port (Arduino IDE, PlatformIO monitor), then try again.
  3. Unplug the X4, plug it back in, wake it, and press Connect and install again.
