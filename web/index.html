Install InkDeck

Markdown writing and a daily journal for the Xteink X3/X4, synced with GitJournal. Fill in your settings, install, and the X4 is ready to sync — no config file, no setup page.

1. Your settings

In GitJournal: Settings → Git Remote Settings → Git Host. SSH or https URL. GitJournal signs in with an SSH key; the X4 uses a token instead. Create a fine-grained token for this repository only, with Contents: Read and write.
Wi-Fi Optional: the installer also asks for Wi-Fi (and checks it) right after installing.
More
Location and writing times Needs a phone app serving InkDeck's location over Bluetooth LE (spec).

These go straight to the X4 over the USB cable. Nothing is uploaded or saved by this page.

2. Install

Your browser can't talk to USB devices. Use Chrome or Edge on a computer (not Safari, Firefox, or a phone). This page has to be opened over HTTPS (or from localhost) to reach USB devices.

Plug the X4 in with a USB-C data cable and wake it, press the button, and pick USB JTAG/serial debug unit. Already running InkDeck?

What happens

  1. Install. The installer writes InkDeck to the X4 (about a minute). Choose erase for a clean install; it clears saved settings and Bluetooth pairings, not your SD card.
  2. Wi-Fi. When the X4 restarts, the installer asks for your Wi-Fi network. Enter it there (it's checked on the spot), or skip it if you filled in Wi-Fi above.
  3. Settings. Close the installer: this page sends your settings over the same cable and the X4 shows Settings received. Choose Sync in its menu to pull your journal.
The X4 turns Bluetooth off while it's on Wi-Fi, so a paired keyboard reconnects once sync finishes. You can also change settings later from Menu → Setup over Wi-Fi, or come back here and use Send settings only.

If it doesn't connect

  1. Check the cable carries data (some USB-C cables only charge).
  2. Close any other program using the port (Arduino IDE, PlatformIO monitor), then try again.
  3. Unplug the X4, plug it back in, wake it, and press Connect and install again.

GitHub is the only provider InkDeck syncs with so far. The token and Wi-Fi password are stored on the X4 and sent only to GitHub and your network.
